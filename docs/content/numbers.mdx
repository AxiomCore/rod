# Numbers

Rod handles numbers consistently across languages, despite the underlying differences (e.g., Python `int` vs JavaScript `number`).

```typescript
const schema = rod.number().int().min(0);
```

## Checks

- `.min(value: number)`: Minimum value (inclusive).
- `.max(value: number)`: Maximum value (inclusive).
- `.int()`: Ensures the number is an integer. 
    - In **JavaScript**, checks `Number.isInteger()`.
    - In **Rust/Python**, checks if the value has no fractional part.

## Handling Floats

Rod uses `f64` (double-precision floating point) internally in Rust. 

```typescript
// Accepts 10, 10.5, 20.0
rod.number().min(10).max(20);

// Rejects 10.5
rod.number().int(); 
```

## Coercion (Coming Soon)

Currently, Rod validates types strictly. It does **not** automatically convert string `"42"` to number `42` unless you explicitly use a coercion helper (planned for v0.2).

If you pass `"123"` to `rod.number()`, it will fail with an `InvalidType` error.
