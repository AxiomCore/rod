This page provides a complete reference for all schema types available in Rod.

## Primitives

Primitives are the basic building blocks for all schemas.

### `string`

Defines a schema that validates string types.

```rust
use rod::{string, RodValidator};
use rod::io::json::wrap;
use serde_json::json;

let schema = string();
assert!(schema.validate(&wrap(&json!("hello"))).is_ok());
assert!(schema.validate(&wrap(&json!(123))).is_err());
```

**Methods**

| Method           | Description                                                 |
| ---------------- | ----------------------------------------------------------- |
| `.min(len)`      | Sets a minimum string length (inclusive).                   |
| `.max(len)`      | Sets a maximum string length (inclusive).                   |
| `.length(len)`   | Sets an exact string length.                                |
| `.email()`       | Validates the string is a valid email address.              |
| `.url()`         | Validates the string is a valid URL.                        |
| `.uuid()`        | Validates the string is a valid UUID.                       |
| `.cuid()`        | Validates the string is a valid CUID.                       |
| `.cuid2()`       | Validates the string is a valid CUIDv2.                     |
| `.ulid()`        | Validates the string is a valid ULID.                       |
| `.datetime()`    | Validates the string is a valid RFC 3339 datetime.          |
| `.ip()`          | Validates the string is a valid IPv4 or IPv6 address.       |
| `.regex(re)`     | Validates the string against a regular expression.          |
| `.starts_with(s)`| Asserts the string starts with a given substring.           |
| `.ends_with(s)`  | Asserts the string ends with a given substring.             |
| `.includes(s)`   | Asserts the string includes a given substring.              |
| `.trim()`        | Trims whitespace from the string before validation.         |

### `number`

Defines a schema that validates numeric types.

```rust
use rod::{number, RodValidator};
use rod::io::json::wrap;
use serde_json::json;

let schema = number();
assert!(schema.validate(&wrap(&json!(42.0))).is_ok());
assert!(schema.validate(&wrap(&json!("not a number"))).is_err());
```

**Methods**

| Method      | Description                                     |
| ----------- | ----------------------------------------------- |
| `.min(val)` | Sets a minimum value (inclusive).               |
| `.max(val)` | Sets a maximum value (inclusive).               |
| `.int()`    | Asserts that the number is an integer (no fractional part). |

### `boolean`

Defines a schema that validates boolean types (`true` or `false`).

```rust
use rod::{boolean, RodValidator};
use rod::io::json::wrap;
use serde_json::json;

let schema = boolean();
assert!(schema.validate(&wrap(&json!(true))).is_ok());
assert!(schema.validate(&wrap(&json!(0))).is_err());
```

### `date`

Defines a schema that validates a date string in RFC 3339 format and performs optional range checks.

```rust
use rod::{date, RodValidator};
use rod::io::json::wrap;
use serde_json::json;

let schema = date().min(0); // Min timestamp in milliseconds (e.g., epoch)
assert!(schema.validate(&wrap(&json!("2024-01-01T00:00:00Z"))).is_ok());
assert!(schema.validate(&wrap(&json!("not a date"))).is_err());
```

**Methods**

| Method      | Description                               |
| ----------- | ----------------------------------------- |
| `.min(ms)`  | Sets a minimum date via a Unix timestamp (milliseconds). |
| `.max(ms)`  | Sets a maximum date via a Unix timestamp (milliseconds). |

### `literal`

Defines a schema that only accepts a specific literal value.

```rust
use rod::{literal, RodValidator};
use rod::io::json::wrap;
use serde_json::json;

let schema = literal("admin");
assert!(schema.validate(&wrap(&json!("admin"))).is_ok());
assert!(schema.validate(&wrap(&json!("user"))).is_err());
```

### `enum_type`

Defines a schema that accepts one of a set of string values.

```rust
use rod::{enum_type, RodValidator};
use rod::io::json::wrap;
use serde_json::json;

let schema = enum_type(vec!["pending", "completed", "failed"]);
assert!(schema.validate(&wrap(&json!("pending"))).is_ok());
assert!(schema.validate(&wrap(&json!("in_progress"))).is_err());
```

### `any`

A schema that accepts any input value and passes it through without validation. Use this as an escape hatch.

<Callout type="warning">
Using `any()` bypasses type safety and may cause performance overhead, as the data must be converted to an owned `serde_json::Value`.
</Callout>

### `never`

A schema that will never pass validation for any input.

## Complex Types

These schemas are used to define structured data like objects and arrays.

### `object`

Defines a schema for an object with a specific shape. Created using the `rod_obj!` macro for convenience.

```rust
use rod::{rod_obj, string, number, RodValidator};
use rod::io::json::wrap;
use serde_json::json;

let schema = rod_obj! {
    id: number().int(),
    name: string()
};

let valid_data = json!({ "id": 1, "name": "Rod" });
assert!(schema.validate(&wrap(&valid_data)).is_ok());
```

By default, objects use `strip` behavior, meaning any unrecognized keys in the input are dropped. This can be configured.

**Methods**

| Method          | Description                                                    |
| --------------- | -------------------------------------------------------------- |
| `.strict()`     | Fails validation if any unrecognized keys are present.         |
| `.strip()`      | (Default) Removes any unrecognized keys from the output.       |
| `.passthrough()`| Includes unrecognized keys in the output.                      |
| `.keyof()`      | Creates an `enum_type` schema from the object's keys.          |
| `.deep_partial()`| Makes all fields in the object (and nested objects) optional. |

### `array`

Defines a schema for an array where every element must match a given schema.

```rust
use rod::{array, string, RodValidator};

let schema = array(string());
```

**Methods**

| Method         | Description                                     |
| -------------- | ----------------------------------------------- |
| `.min(len)`    | Sets a minimum array length (inclusive).        |
| `.max(len)`    | Sets a maximum array length (inclusive).        |
| `.nonempty()`  | Shortcut for `.min(1)`.                         |

### `tuple`

Defines a schema for an array with a fixed number of elements, each with a specific type.

```rust
use rod::{tuple, string, number, RodValidator};

let schema = tuple(vec![Box::new(string()), Box::new(number())]);
```

### `record`

Defines a schema for an object with string keys and values of a specific type. Useful for dictionaries or hashmaps.

```rust
use rod::{record, string, number, RodValidator};

// A record with any string key, and number values
let schema = record(string(), number());
```

### `map`

Defines a schema for a map-like structure, represented in JSON as an array of `[key, value]` pairs.

```rust
use rod::{map, string, boolean, RodValidator};

let schema = map(string(), boolean());
```

### `set`

Defines a schema for a set, represented as an array where all elements must be unique and match a given schema.

```rust
use rod::{set, number, RodValidator};

let schema = set(number());
```

**Methods**

| Method     | Description                            |
| ---------- | -------------------------------------- |
| `.min(len)`| Sets a minimum set size (inclusive).   |
| `.max(len)`| Sets a maximum set size (inclusive).   |

### `union`

Defines a schema that accepts a value matching any one of the provided schemas.

```rust
use rod::{union, string, number, RodValidator};

let schema = union(vec![Box::new(string()), Box::new(number())]);
```

### `intersection`

Defines a schema that merges two object schemas. The input data must be valid against both.

```rust
use rod::{rod_obj, intersection, string, number, RodValidator};

let schema1 = rod_obj!{ name: string() };
let schema2 = rod_obj!{ age: number() };
let merged_schema = intersection(schema1, schema2);
```

### `discriminated_union`

A highly efficient way to validate a union of objects based on a shared literal field (the "discriminator").

```rust
use rod::{discriminated_union, rod_obj, literal, string, number, RodValidator};

let dog_schema = rod_obj! { type: literal("dog"), breed: string() };
let cat_schema = rod_obj! { type: literal("cat"), lives: number().int() };

let schema = discriminated_union("type", vec![
    ("dog", Box::new(dog_schema)),
    ("cat", Box::new(cat_schema)),
]);
```

### `lazy`

Allows for the definition of recursive schemas, where a schema refers to itself.

```rust
use rod::{lazy, rod_obj, string, array, RodValidator};

// Example of a category with nested sub-categories
let category_schema = rod_obj! {
    name: string(),
    subcategories: array(lazy(|| Box::new(category_schema.clone())))
};
```

## Modifiers

Modifiers are chained onto other schemas to alter their validation behavior, such as making them optional.

### `optional`

Makes a schema optional. In an object, if the key is missing, validation will pass.

```rust
use rod::{string, OptionalExtension, RodValidator};

let schema = string().optional();
```

### `nullable`

Allows a schema to accept `null` as a valid value in addition to its own type.

```rust
use rod::{string, NullableExtension, RodValidator};

let schema = string().nullable();
```
