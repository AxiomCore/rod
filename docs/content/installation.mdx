# Installation

Rod consists of a core Rust library and bindings for JavaScript and Python. Choose the installation method for your environment.

<Tabs items={['Rust', 'JavaScript / TypeScript', 'Python']}>

<Tab value="Rust">

Add `rod` to your `Cargo.toml`.

```bash
cargo add rod
```

Or manually add it to your dependencies:

```toml
[dependencies]
rod = "0.1.0"
```

</Tab>

<Tab value="JavaScript / TypeScript">

Rod is available as an NPM package that includes the WebAssembly binaries. It works in both Node.js and the Browser.

```bash
npm install rod-js
# or
pnpm add rod-js
# or
yarn add rod-js
```

</Tab>

<Tab value="Python">

Rod provides a native Python extension compiled via PyO3.

```bash
pip install rod
```

*Note: Requires Python 3.8+*

</Tab>

</Tabs>

## Prerequisites

- **Rust:** Requires generic associated types (GATs), so a relatively modern Rust compiler (1.65+) is recommended.
- **JavaScript:** The WASM bindings require an environment that supports `WebAssembly`.
  - Node.js 18+
  - Modern Browsers (Chrome, Firefox, Safari, Edge)
- **Python:** Python 3.8 or newer.
