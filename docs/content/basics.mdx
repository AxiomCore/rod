This page covers the fundamentals of Rod: defining schemas, validating data, and handling results.

## Defining a Schema

The first step is to define a schema using Rod's builder functions and macros.

```rust
use rod::{rod_obj, string, number, array};

let player_schema = rod_obj! {
    username: string().min(3),
    level: number().int().min(1.0),
    tags: array(string())
};
```

## Parsing Data

To validate data against a schema, use the `.validate()` method. Since Rod operates on borrowed data, you'll typically wrap your input (e.g., a `serde_json::Value`) using an adapter.

The `validate` method returns a `RodResult`, which is a standard Rust `Result`.

```rust
use rod::io::json::wrap;
use rod::RodValidator; // Import the trait
use serde_json::json;

// Some untrusted data
let input = json!({
    "username": "rod_user",
    "level": 10,
    "tags": ["rust", "validation"]
});

let result = player_schema.validate(&wrap(&input));

assert!(result.is_ok());

// The Ok variant contains a `RodValue` which holds the validated data.
let validated_data = result.unwrap();
```

## Handling Errors

If validation fails, `.validate()` returns an `Err` variant containing a `RodError`. This error struct contains a list of all validation issues found.

```rust
let invalid_input = json!({
    "username": "no", // too short
    "level": 0.5,     // not an integer
    "tags": [123]     // contains a number, not a string
});

let result = player_schema.validate(&wrap(&invalid_input));

assert!(result.is_err());

if let Err(error) = result {
    // error.issues is a Vec<RodIssue>
    assert_eq!(error.issues.len(), 3);
    
    // You can inspect each issue for details
    for issue in error.issues {
        println!("Validation error at path '{:?}': {}", issue.path, issue.message);
    }
}
```

This granular error reporting is ideal for building API responses where you want to inform the client of all errors at once.

## Type Safety

After a successful validation, you can work with the resulting `RodValue` with full confidence. While it's a dynamic structure, its contents have been verified to match the schema you defined.
