# Dynamic Schemas (RodSpec)

While the builder API is excellent for compile-time schemas, there are cases where you need to define validation rules at runtime—such as loading configuration from a database or a shared YAML file.

**RodSpec** is the serializable AST (Abstract Syntax Tree) that defines a Rod schema. It is the language-agnostic intermediate representation used by Rod to transport logic across language boundaries.

## Bi-Directional Portability

With the latest version of Rod, the relationship between a **Validator** (executable code) and a **Spec** (serializable data) is bi-directional.

1. **Build:** `Spec -> Validator` (Run your JSON rules).
2. **Introspect:** `Validator -> Spec` (Turn code back into JSON).

### Round-tripping Example (Rust)

```rust
use rod_rs::{string, RodSpec, RodValidator};

// 1. Create a validator via Builder API
let original_validator = string().min(10).email();

// 2. Introspect: Convert Validator back to a Spec
let spec: RodSpec = original_validator.to_spec();

// 3. Serialize to JSON
let json_string = serde_json::to_string(&spec).unwrap();

// 4. Reload: Convert JSON back to an executable validator
let reloaded_spec: RodSpec = serde_json::from_str(&json_string).unwrap();
let new_validator = reloaded_spec.build();
```

## Usage across Languages

    use rod_rs::RodSpec;

    let spec_json = json!({

        "properties": {
            "name": { "type": "string", "min": 3 },
            "age": { "type": "number", "int": true }

    let spec: RodSpec = serde_json::from_value(spec_json).unwrap();
    let validator = spec.build();

## Why use RodSpec over JSON Schema?

While Rod supports [exporting to JSON Schema](./json-schema), the `RodSpec` format is preferred for **Internal Rod communication** because:
1. **Precision:** It captures Rod-specific features like `trim`, `cuid`, and `transform` exactly.
2. **Speed:** Parsing a `RodSpec` into a Rod validator is significantly faster than parsing a generic JSON Schema.
3. **Native:** It maps 1-to-1 with the Rust Enum variants used in the core engine.
