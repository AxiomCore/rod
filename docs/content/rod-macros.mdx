# Procedural Macros

The `#[derive(Rod)]` macro allows you to turn Rust structs into validation engines and self-documenting JSON Schemas simultaneously.

## Automatic Method Generation

When you derive `Rod` on a struct, the macro generates several useful methods:

1. **`::schema()`**: Returns an executable `Box<dyn RodValidator>`.
2. **`::spec()`**: Returns the internal `RodSpec` metadata.
3. **`::json_schema()`**: Returns a standard **JSON Schema Draft 2020-12** object.

```rust
#[derive(Rod)]
struct User {
    #[rod(min = 3)]
    name: String,
    age: u32,
}

// 1. For Validation
let validator = User::schema();

// 2. For External Tools (Postgres, Swagger)
let json = User::json_schema();
```

## Generic Bound Injection

The macro is "Generic-Aware." If you define a generic struct, the macro automatically injects the `T: RodSchema` bound so you don't have to write it manually.

```rust
#[derive(Rod)]
struct Envelope<T> {
    id: String,
    data: T, // Macro adds 'where T: RodSchema'
}
```

## Tuple Structs

Positional tuple structs are fully supported and export to JSON Schema using the `prefixItems` keyword.

```rust
#[derive(Rod)]
struct Coords(f64, f64);

// Produces: { "type": "array", "prefixItems": [{ "type": "number" }, { "type": "number" }] }
let json = Coords::json_schema();
```

## Support Matrix

| Rust Category | Mapping Logic | JSON Schema Support |
| :--- | :--- | :--- |
| **Primitives** | `String`, `i32`, `bool`, `f64`, etc. | Full |
| **Optional** | `Option<T>` maps to `nullable().optional()`. | Excluded from `required` |
| **Collections** | `Vec<T>`, `HashSet<T>`, `HashMap<K, V>`. | Full |
| **Pointers** | `Box<T>`, `Arc<T>`, `Rc<T>`, `Cow<T>`. | Full (Unwrapped) |
| **References** | `&str`, `&T`. | Full (Unwrapped) |

## Advanced Attributes

| Attribute | Logic |
| :--- | :--- |
| `#[rod(min = 5)]` | Minimum value for numbers, minimum length for strings. |
| `#[rod(max = 10)]` | Maximum value for numbers, maximum length for strings. |
| `#[rod(email)]` | Validates email format. |
| `#[rod(uuid)]` | Validates UUID v4. |
| `#[rod(cuid)]` | Validates CUID and exports as regex pattern. |
| `#[rod(regex = "...")]` | Custom regular expression validation. |

<Callout type="warn">
**Attribute Errors:** The Rod macro will fail to compile if you provide invalid attributes (e.g., `#[rod(min = "not-a-number")]`), providing a clear error message pointing to the exact field.
</Callout>
